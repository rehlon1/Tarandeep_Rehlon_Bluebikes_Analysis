# Tableau

The final project used a packaged Tableau workbook containing four dashboards and multiple data extracts.

The original `.twbx` is approximately **133 MB**, which is larger than GitHub's normal single-file limit and contains large project extracts, so it is intentionally not committed to this public portfolio repository.

Instead, this folder documents the Tableau work in a reviewable form:

- [Calculated Fields](calculated-fields.md)
- [Workbook Structure](workbook-structure.md)

The dashboard layer covers:

1. Executive Overview
2. Demand & User Behaviour
3. Stations & Operations
4. Weather & Demand

The underlying SQL and Python preparation code is included elsewhere in the repository.
