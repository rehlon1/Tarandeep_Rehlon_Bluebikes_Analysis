# Tableau Workbook Structure

The packaged Tableau workbook contains **4 dashboards** and **26 worksheets**.

## Dashboards

1. **Executive Overview**
2. **Demand & User Behaviour**
3. **Stations & Operations**
4. **Weather Impact** - presented in the final project narrative as Weather & Demand

## Selected worksheets

### Executive / growth
- Total Journey KPI
- Journey Growth KPI
- KPI Subscriber Share
- Median Journey Duration KPI
- Journeys by Year
- Monthly Journey Trend (2016-2019)
- Journeys by District

### User behaviour
- Hourly Journey Pattern
- Hourly Journey Pattern by User Type
- Journeys by Day of Week
- Weekday vs Weekend by User Type
- Median Journey Duration by User Type
- Subscribers Vs Consumers
- User Type Trend by Year
- Journey Demand Heatmap

### Stations & operations
- Top 10 Start Stations
- Bottom 10 Start Stations
- Station Demand Map
- Station Usage per Dock
- Station Flow Imbalance

### Weather
- Rainfall Demand Impact
- Rainfall vs Journeys
- Snowfall Impact
- Temperature vs Journeys

## Design intent

The dashboard sequence moves from:

**system growth → user behaviour → station pressure → external demand conditions**

This keeps the stakeholder walkthrough decision-focused while allowing supporting evidence to be explored through filters and individual worksheets.
